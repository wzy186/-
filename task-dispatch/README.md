# task-dispatch — 分布式脚本任务分发系统

接收用户提交的 Python 脚本任务，分发到 5 个执行节点运行，并返回执行结果。业务方只感知一个"普通的计算接口"。

## 一句话架构

业务方 → **Coordinator**（唯一状态写者，SQLite 持久化，原子领取）→ 5 × **Worker**（独立进程、仅 HTTP 通信、节点内并发池）。任务恰好执行一次：原子领取（单条 `UPDATE ... RETURNING`）+ 状态机前置条件 + 心跳租约超时回收 + 幂等回写。

## 状态机

```
queued → running → succeeded / failed
   ▲        │
   └─requeue┘（心跳过期且未达重试上限）
```
